# Spice-ai-canvas 
# AI-Website-Project-Restaurant website

## 📌 Project Description
This repository contains a professional website project created as part of the Generative AI course (Assignment) at Superior University. The website was designed and developed using advanced Generative AI tools without writing traditional code manually, demonstrating the power of AI-assisted web development.

---

## 🛠️ AI Tool Used
Tool Name:[Lovable AI / ChatGPT]
Purpose:Used for generating the website layout, UI components, styling, and responsive design.

---

## 💬 Prompt Used
> "[Create a professional, modern, and attractive restaurant website named Spice Haven, with the tagline "A Taste of Tradition."

The restaurant specializes in traditional Pakistani cuisine.

Design Requirements:

- Use a beautiful combination of cream, deep green, and terracotta colors.
- Create a clean, elegant, and professional layout.
- Make the website fully responsive for mobile and desktop.
- Use high-quality food images.
- Add smooth navigation and attractive buttons.

Website Sections:

1. Home Page: A welcoming hero section with the restaurant name, tagline, delicious food image, and a "Explore Our Menu" button.

2. About Us: Introduce Spice Haven, its passion for traditional Pakistani food, and its commitment to quality and taste.

3. Our Menu: Display different Pakistani food items with attractive images, names, short descriptions, and prices.

4. Special Dishes: Highlight the restaurant's most popular dishes.

5. Contact Us: Include restaurant contact information, address, opening hours, and a contact form.

6. Table Reservation: Add a simple reservation form where customers can submit their name, date, time, and number of guests.

Important: Make the website visually appealing, easy to navigate, and suitable for a real restaurant business. Ensure all sections and buttons work properly..']"

---

## ✨ Features List
* Modern and responsive landing page layout.
* Interactive UI components (Navigation bar, Hero section, Gallery/Menu).
* Professional color scheme and typography.
* Contact section / Inquiry for food
